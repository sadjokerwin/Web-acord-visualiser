# Web Chord Visualiser - Библиотека с песни

## Описание на проекта

Web приложение за визуализация на песни и китарни акорди, построено с HTML, CSS, JavaScript и PHP.

## Структура на проекта

```
Web-acord-visualiser/
│
├── setup.php                    # Скрипт за инициализация на базата данни
│
├── frontend/                    # Frontend файлове
│   ├── index.html              # Основен HTML файл
│   ├── css/
│   │   └── style.css           # Стилове
│   └── js/
│       ├── config.js           # Конфигурация и API endpoints
│       ├── app.js              # Инициализация на приложението
│       ├── songManager.js      # Управление на списък с песни
│       ├── songDetails.js      # Зареждане на детайли за песен
│       ├── audioPlayer.js      # Web Audio API за възпроизвеждане на акорди
│       ├── chordDisplay.js     # ASCII визуализация на акорди
│       ├── lyricsFormatter.js  # Форматиране на текстове с акорди
│       ├── uiHandlers.js       # Event handlers за UI
│       ├── exportManager.js    # Експорт в PDF/JSON/CSV

│   ├── get_song_details.php    # Връща детайли за конкретна песен
```

## Стъпки за изпълнение

### 1. Инсталация и настройка на XAMPP

1. Уверете се, че XAMPP е инсталиран и работи
2. Стартирайте Apache и MySQL от XAMPP Control Panel

### 2. Създаване на базата данни

1. Отворете браузър и навигирайте до:

   ```
   http://localhost/Web-acord-visualiser/setup.php
   ```

2. Ще видите съобщение: "Базата данни и таблиците са създадени успешно с примерни данни!"

3. Това създава:
   - База данни `chord_project`
   - Таблица `songs` с 10 предварително подбрани песни
   - Таблица `chords` с акордите за всяка песен

### 3. Отваряне на приложението

Отворете в браузър:

```
http://localhost/Web-acord-visualiser/frontend/index.html
```

### 4. Използване на приложението

1. **Начална страница** - Виждате grid с всички налични песни
2. **Избор на песен** - Кликнете на картичка с песен
3. **Детайли на песен** - Вижте текста и акордите
4. **Бързо зареждане** - Текстът се кешира в БД за моментално следващо зареждане
5. **Назад** - Бутон за връщане към началната страница

## Функционалност

### Frontend (frontend/)

Модулна архитектура с разделени отговорности:

- **index.html** - Две отделни страници: начална (списък) и детайли
- **style.css** - Минималистичен дизайн, grid layout за песни
- **config.js** - Конфигурация на API endpoints и глобално състояние
- **app.js** - Инициализация и setup на приложението
- **songManager.js** - Зареждане, филтриране и показване на списък с песни
- **songDetails.js** - Зареждане на детайли, кеширане и автоматично зареждане на текстове от API
- **audioPlayer.js** - Web Audio API за синтезиране на звукове на китарни акорди с честоти
- **chordDisplay.js** - ASCII визуализация на китарни акорди
- **lyricsFormatter.js** - Форматиране на текстове с позициониране на акорди
- **uiHandlers.js** - Event handlers за навигация, експорт и филтриране
- **exportManager.js** - Експорт в PDF (jsPDF), JSON и CSV формати
- **importManager.js** - Импорт на песни от JSON и CSV файлове с валидация
- **favorites.js** - Управление на любими песни с LocalStorage

### Backend (backend/)

- **get_songs.php** - Връща JSON списък с всички песни
- **get_song_details.php** - Връща информация за песен с акорди и текст
- **save_lyrics.php** - Запазва текст на песен в БД (кеширане)
- **save_imported_song.php** - Запазва импортирана песен с акорди

### Models (models/)

- **Database.php** - PDO връзка с MySQL, singleton pattern
- **Song.php** - Методи за работа с песни и акорди

## API интеграция

Приложението използва следните API-та:

### Външни API-та
- **Lyrics API** - `https://api.lyrics.ovh/v1/{artist}/{title}` за автоматично зареждане на текстове
- **SoundCloud Embed API** - За вграждане на плеър на SoundCloud
- **jsPDF CDN** - За генериране на PDF експорти

### Вътрешни API endpoints
- `/backend/get_songs.php` - Списък със всички песни
- `/backend/get_song_details.php?id={songId}` - Детайли на песен
- `/backend/save_lyrics.php` - Кеширане на текстове
- `/backend/save_imported_song.php` - Запазване на импортирани песни

### Кеширане и обработка
- Текстовете се кешират в БД след първо зареждане за бързо зареждане
- Retry логика с exponential backoff за API заявки
- 6-секундна timeout за Lyrics API със 2 опита
- Web Audio API за генериране на звукове на акорди

## Добавяне на нови песни

За да добавите нови песни, редактирайте `setup.php` файла:

```php
$stmt = $pdo->prepare("INSERT IGNORE INTO songs (id, title, artist) VALUES (?, ?, ?)");
$stmt->execute([3, 'Име на песента', 'Изпълнител']);

$chords = [
    ['Am', 'x02210', 0],
    ['F', 'xx3211', 1],
    // ... добавете акорди
];
```

След това изпълнете setup.php отново.
